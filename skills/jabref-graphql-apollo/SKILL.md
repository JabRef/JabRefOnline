# JabRef Online GraphQL and Apollo

JabRef Online uses GraphQL SDL files, GraphQL Code Generator, Apollo Client, and Vue Apollo composables.

## Server GraphQL

1. Add or edit SDL in `server/**/schema.graphql`.
   - Domain SDL is colocated under folders such as `server/documents/`, `server/groups/`, `server/journals/`, and `server/user/`.
   - Shared or root schema definitions live in `server/schema.graphql`.
2. Implement matching resolvers in `server/<domain>/resolvers.ts`.
3. Use generated resolver types from `#graphql/resolver`.
4. Keep resolver return objects aligned with generated GraphQL types and union/interface resolution.

## Code Generation

Run code generation after GraphQL SDL or operation changes:

```bash
pnpm graphql:generate
```

Use watch mode when iterating:

```bash
pnpm graphql:generate:watch
```

Validate operations against the schema before finishing GraphQL work:

```bash
pnpm graphql:validate
```

The codegen config in `graphql.config.json`:

- Reads schema files from `server/**/*.graphql`.
- Reads operations from Vue files under `pages/` and `components/`, plus selected plugin, middleware, Apollo, and server test files.
- Generates typed documents and GraphQL types under `apollo/generated/`.
- Uses `gql` as the typed document tag name.

## Vue Apollo

- Import `gql` from `~/apollo`.
- Use `gql(/* GraphQL */ \`...\`)` for queries, mutations, and fragments.
- Use `useQuery`, `useMutation`, or `useApolloClient` from `@vue/apollo-composable`.
- Keep reusable fragments close to the consuming component, as in `DocumentView.vue` and `DocumentEditor.vue`.
- For authenticated calls, rely on the configured Apollo plugin sending cookies with `credentials: 'include'`.

## Apollo Cache

- Update `apollo/cache.ts` when GraphQL interface or union relationships need client cache awareness.
- Keep introspection and generated cache artifacts generated by codegen; do not hand-edit generated files.
